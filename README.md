# PrettyMD Privacy Policy

**Last updated:** 6 November 2026
**Applies to:** PrettyMD version 0.6.1

PrettyMD is a Chrome extension that displays local Markdown (`.md`) files as formatted pages and lets you edit them.

## Summary

PrettyMD processes Markdown documents locally to display and edit them. It does not send document contents to the developer and includes no analytics, advertising or telemetry. External images referenced in documents may contact their hosting websites.

## Your documents

- PrettyMD reads and processes Markdown files **locally in your browser** to display them and, if you choose, to let you edit them.
- Document contents are **never sent** to the developer or to any other service.
- PrettyMD includes **no analytics, tracking, advertising or telemetry**.

## Unsaved edits

Edits you make are held only in the current page. If you close or leave the page without saving, they are lost. PrettyMD does not keep backups or drafts elsewhere.

## Settings

PrettyMD stores a small number of display preferences, such as your light/dark theme, using Chrome's local extension storage (`chrome.storage.local`). These settings stay on your device, are not synced across devices, and contain no document content or personal information. Uninstalling PrettyMD deletes them.

## External content

- If a Markdown document references an image hosted on a website (for example, `https://example.com/image.png`), your browser contacts that website to load it, just as with any web page. That website may see your IP address and browser details under its own privacy policy. PrettyMD does not control or receive this information.
- All of PrettyMD's own code, fonts and libraries are bundled inside the extension. It loads no code from remote servers.

## Saving files

- PrettyMD writes files **only when you choose to save**.
- The first time you save, Chrome asks you to choose a file and grant permission. Later saves in the same session write to that chosen file without asking again.
- Files you save remain on your device after you uninstall PrettyMD.

## Permissions

PrettyMD requests only the permissions it needs to display and edit Markdown files and remember your settings. It does not use them to collect information about you or your browsing.

## Limited use

Any user data PrettyMD handles is used only to provide its disclosed functionality: displaying, editing and saving Markdown files, and remembering your settings. It is not sold, not transferred to third parties, not used for purposes unrelated to that functionality, and not used to determine creditworthiness or for lending purposes.

## Children

PrettyMD collects no personal information from anyone, including children.

## Changes to this policy

If PrettyMD's features or data handling change, this policy will be updated at this page with a new "Last updated" date.
